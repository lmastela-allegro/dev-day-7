Nawigacja i klawiatura

Odłóż mysz. Wszystkie przykłady na tej stronie przetestuj klawiszami Tab, Shift+Tab i Enter.

Link „Przejdź do treści”

Kryterium 2.4.1 · A

Przeładuj tę stronę i naciśnij Tab. Pierwszym elementem jest ukryty link, który pojawia się po otrzymaniu fokusu. Pozwala ominąć menu i przejść od razu do <main>.

<a class="skip-link" href="#main">Przejdź do treści</a>
…
<main id="main" tabindex="-1">

.skip-link { position: absolute; top: -10rem; }
.skip-link:focus { top: 1rem; }

Menu nawigacyjne

Kryteria 2.1.1 · A, 4.1.2 · A, 1.3.1 · A

Pomiń zły przykład

✗ Źle

Produkty Cennik Kontakt

✓ Dobrze

  • Produkty
  • Cennik
  • Kontakt
<!-- ✗ --> <span onclick="go('/cennik')">Cennik</span>
<!-- ✓ --> <nav aria-label="Główna"><ul><li><a href="/cennik">Cennik</a></li>…</ul></nav>

Elementy <span> z onclick są pomijane przez Tab. Czytnik ekranu nie rozpozna ich jako linków ani nie ogłosi obszaru nawigacji. Linki w <nav> działają od razu, a aria-current informuje, która strona jest aktywna.

Widoczny fokus

Kryterium 2.4.7 · AA

✗ Źle: outline: none

Pomoc

✓ Dobrze: wyraźny :focus-visible

Pomoc 

/* ✗ */ button:focus { outline: none; }
/* ✓ */ :focus-visible { outline: 3px solid #b3006b; outline-offset: 3px; }

Przejdź Tab przez oba zestawy. W lewym nie wiesz, gdzie jesteś. :focus-visible pokazuje obramowanie przy nawigacji klawiaturą, a przy kliknięciu myszą zwykle go nie pokazuje.

Kolejność fokusu

Kryterium 2.4.3 · A

✗ Źle: dodatni tabindex

✓ Dobrze: kolejność z DOM

Dodatni tabindex przenosi elementy na początek kolejności całej strony. Po przeładowaniu i kilku naciśnięciach Tab fokus trafi najpierw do „Nazwiska” po lewej, z pominięciem menu i treści. Zamiast tego ustaw elementy w kodzie w logicznej kolejności.
